# 통합과학 2 · 펜슬 문제집

355문제를 풀면서 Apple Pencil로 필기하는 아이패드용 웹앱입니다.

## 아이패드에서 실행

1. Safari로 배포된 개인용 주소를 엽니다. 배포 주소는 작업 완료 메시지와 상위 폴더의 아이패드 사용안내에 있습니다.
2. 이 사이트를 만든 ChatGPT 계정으로 로그인합니다.
3. Safari 공유 메뉴에서 **홈 화면에 추가**를 선택합니다.
4. 홈 화면 아이콘으로 실행하고 **펜**을 선택해 필기합니다.

웹앱이므로 App Store 설치나 개발자 서명은 필요하지 않습니다.

## 필기

- 펜, 형광펜, 지우개, 4색, 굵기 조절, 실행 취소와 다시 실행을 지원합니다.
- 펜슬 전용 모드에서는 손가락 입력이 선으로 기록되지 않습니다. 마우스로도 쓸 수 있습니다.
- 필기 모드는 종이 위 스크롤을 잠급니다. 스크롤·핀치 확대를 하려면 **이동** 도구로 바꾸세요.
- 문제 아래 빈 공간도 필기할 수 있습니다.
- 필압을 보고하는 펜슬에서는 압력에 따라 펜 굵기를 조절합니다. 이중 탭·스퀴즈는 지원하지 않습니다.
- 원본 페이지는 확인용이며 필기는 개별 문제 화면에 저장합니다.

## 저장과 오프라인

필기는 브라우저의 IndexedDB에 문제별로 저장됩니다. 다음 문제로 이동하거나 앱을 다시 열어도 복원됩니다. 화면 크기를 바꿔도 같은 좌표에 표시됩니다.

**보관함 · 백업**에서 필기를 JSON 파일로 내보내거나 복원하고, 현재 풀이를 PNG 이미지로 저장할 수 있습니다. 복원은 백업에 있는 문제의 필기만 덮어쓰며, 별표 목록은 합칩니다.

기기 간 자동 동기화는 없습니다. Safari와 홈 화면 앱의 저장 공간이 다를 수 있으므로 이동할 때는 백업을 이용하세요. 사이트 데이터 삭제 또는 운영체제의 저장 공간 정리로 데이터가 사라질 수 있습니다.

**오프라인용 문제 저장**을 누르면 모든 문제와 원본 페이지를 기기에 저장합니다. 약 14MB이며 HTTPS 또는 localhost에서 동작합니다. 첫 접속과 로그인에는 인터넷이 필요합니다. 비공개 사이트의 인증 페이지가 먼저 나타나는 경우 온라인으로 로그인한 뒤 사용하세요. 브라우저가 캐시를 삭제한 경우 다시 저장해야 합니다.

## 개발과 검증

- [dist/](./dist/): 설치 없이 배포할 수 있는 HTML/CSS/JavaScript 정적 앱 및 문제 이미지
- [prepare_assets.py](./prepare_assets.py): 상위 폴더의 기존 문제 목록과 이미지에서 웹용 WebP 자료 생성
- [test_browser.py](./test_browser.py): Chromium/WebKit의 태블릿 화면, 필기, 저장, 복원, 오프라인 검증

로컬 실행: `python serve.py`

테스트: `python -m pip install playwright` 및 `python -m playwright install chromium webkit` 후 `python test_browser.py`

브라우저 자동 테스트는 실제 iPad·Apple Pencil 하드웨어 테스트를 대신하지 않습니다.
